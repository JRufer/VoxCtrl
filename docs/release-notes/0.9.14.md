**New: set up a server from Settings → General.** A **VoxCtrl Server** panel
puts the whole client setup in one place, so you no longer need the setup
wizard, or to visit three tabs, to use a server:

- Enter the server's address and API key and click **Connect**. The machine's
  name or IP address is enough; the rest of the address is filled in. The
  panel then says what that server offers.
- Switch on what to use it for: **speech recognition** (with the engine that
  takes over when the server can't be reached), **dictation cleanup**, and
  **text-to-speech**. Switching one off goes back to what you used before.

These are the same settings the Engine and TTS tabs show; the finer options,
such as the server's speech engine and voice, stay on those tabs.
