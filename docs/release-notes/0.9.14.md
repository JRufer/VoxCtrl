**Server setup in one place: Settings → Engine → Remote Speech Engine.**
Choosing **Remote Speech Engine** as the backend now covers the whole client
setup, so you no longer need the setup wizard to use a server:

- **Just the machine's name or IP address.** Type `192.168.1.50` as the
  endpoint and it is completed to `http://192.168.1.50:8787/v1`. An address
  typed in full, such as another OpenAI-compatible service, is left as it is.
- **Test Connection says what the server offers**: speech recognition,
  dictation cleanup and text-to-speech. What a server lacks is explained next
  to the option that needs it.
- **New option: Use the server for text-to-speech**, next to the existing
  fallback engine and server cleanup options. It sets the TTS engine to
  **VoxCtrl server**; the server's engine and voice are still chosen under
  **TTS**. Switching it off goes back to the TTS engine you used before.
