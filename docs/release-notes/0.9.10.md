**Fixed: Kitten TTS 2, VoxCPM2, Breeze-TTS-2 and Pocket-TTS failed on CPUs
without AVX-512.** Since 0.9.4, speaking with any of these four engines could
fail with "Connection refused" or "connection closed before message completed"
(0.9.9 shows it as the engine stopping with `SIGILL`, "Illegal instruction").
The speech runtime VoxCtrl downloaded for them was a build that only runs on
processors with AVX-512, which most desktop CPUs do not have.

VoxCtrl now installs the portable build of the same runtime, which runs on any
64-bit Intel or AMD processor. An existing install is replaced automatically
the next time the app starts with one of these engines selected, or on the
next speech request: an 88 MB download, once. Your models and voices are kept.

The same fix applies to a VoxCtrl server using one of these engines; rebuild or
restart it to pick it up.
