**New voice engine: Reverb-TTS.** Software Mansion's
[Reverb-TTS](https://huggingface.co/software-mansion/Reverb-TTS) is a
297M-parameter voice-cloning model for English, German, French, Spanish,
Italian, Polish and Portuguese. It's small and quick (an 875 MB download, about
2 GB of memory, a tenth of a second per reply on a fast GPU) and its English is
as accurate as models several times its size. Pick it under **Settings → TTS**:

- 16 built-in voices, listed by language, or clone any clip in your voices
  folder that has a matching `.txt` transcript.
- A language picker. Any voice can speak all seven languages.
- GPU acceleration through Vulkan, as for the other audio.cpp engines.

The weights are CC BY-NC 4.0, so non-commercial use only. Settings shows the
notice before you download.

**Reverb-TTS needs an audio.cpp build that has it, for now.** Support is in
review upstream and isn't in an audio.cpp release yet. Until it is, build
`audiocpp_server` from the `reverb-tts` branch and enter its path in the new
**audio.cpp server** field:

```bash
git clone -b reverb-tts https://github.com/JRufer/audio.cpp
cd audio.cpp
cmake -B build -DCMAKE_BUILD_TYPE=Release -DENGINE_ENABLE_VULKAN=ON
cmake --build build -j 4 --target audiocpp_server   # a bare -j has no limit and can run out of RAM
```

Building the AppImage yourself? `./build_appimage.sh --audiocpp-server=PATH`
puts that server inside it, so Reverb-TTS works with no setting.

Settings says plainly when the runtime can't run Reverb-TTS. Once a release
includes it, VoxCtrl's own runtime will run it and the field becomes optional.
The setup wizard will offer Reverb-TTS then too.

**audio.cpp server setting.** `tts.audiocpp_server` points every audio.cpp
engine (Pocket-TTS, Breeze-TTS-2, VoxCPM2, Kitten TTS 2, Reverb-TTS) at an
`audiocpp_server` of your own instead of the one VoxCtrl manages. It's useful
for testing new audio.cpp builds or a CUDA build. Leave it blank to keep the
managed runtime.

**On the server.** `voxctrl-server` can offer `reverb` to clients, with its
built-in voices and clients' uploaded voices. Point it at a Reverb-capable
build with `[tts] audiocpp_server` or `VOXCTRL_SERVER_AUDIOCPP_SERVER`.
