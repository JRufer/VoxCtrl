**New: an AUR package for the server.**

On Arch and Arch-based systems, `voxctrl-server` installs the headless VoxCtrl
server as a system service:

```bash
paru -S voxctrl-server
sudo systemctl enable --now voxctrl-server
sudo -u voxctrl -H voxctrl-server --pairing-code
```

- No desktop dependencies: it is for a machine nobody sits at, where the
  AppImage's `--server` mode can't run.
- Installs the systemd service, the `voxctrl` service user and
  `/var/lib/voxctrl`, where settings and models are kept.
- whisper.cpp and dictation cleanup use the GPU when a Vulkan driver is
  installed.
- Can be installed next to the `voxctrl` app packages.

It is built from source on your machine. The package appears on the AUR when
this release is published. Nothing changes in the app itself in this release.
See [Server → Arch Linux](https://github.com/JRufer/VoxCtrl/blob/master/docs/server.md#arch-linux-aur).
