**Hardening ahead of 1.0.** Fixes from a review of the whole codebase before
the first release candidate.

**New servers are encrypted.** A server set up from scratch now serves HTTPS
only, with a certificate it makes for itself. Connect each app by pasting the
server's pairing code (`voxctrl-server --pairing-code`).

- **An existing server keeps working as it was.** A `server.toml` written by an
  earlier release that has no `[tls]` section stays on plain HTTP, so no app
  is disconnected by the upgrade. To encrypt it, set `enabled = true` under
  `[tls]` (or `VOXCTRL_SERVER_TLS=true`) and pair each app again.
- **One exception:** a server with no `server.toml` at all, run with its API
  key set only by `VOXCTRL_SERVER_API_KEY`, now starts encrypted. Set
  `VOXCTRL_SERVER_TLS=false` to keep plain HTTP.
- An app that speaks plain HTTP to an encrypted server is now told to paste
  the pairing code, instead of seeing the connection close with no reason.
- A server running without encryption says so as a warning when it starts.

**The app and the server check each other's versions.** The server's `/health`
now says which client contract it speaks and the oldest app it works with.
Settings → Engine says when the server is older than this app expects, and the
app switches to the fallback engine, and says to update, if the server needs a
newer app.

**Fewer wasted uploads.** When the server refused a dictation (a wrong key, a
transcription that failed, a full server), the app sent the whole recording a
second time before reporting it. It now reports the server's own message
straight away. A second upload happens only when a server rejects streamed
uploads, as some other OpenAI-compatible servers do.

**Fixed: dictated text in the log.** Voice commands and Exec targets wrote the
dictated words into the app's log output (the journal, on most desktops),
contrary to VoxCtrl's privacy rules. They now log how many words there were. A
check in CI keeps it that way.

**Tests.** Every crate's tests now run on each pull request; over 200 had been
left out by mistake.
