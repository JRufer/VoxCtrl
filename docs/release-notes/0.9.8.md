**Fixed: server text-to-speech failed with the neural engines.** With
Pocket-TTS, Kitten TTS 2, Breeze-TTS-2 or VoxCPM2 as the server's engine,
speech requests failed with "Connection refused" or "connection closed before
message completed" on a `127.0.0.1` address. The engine's helper process was
being shut down a few seconds after it started, sometimes in the middle of a
request. The server now keeps it running for as long as the server does.
Rebuild the server (or its Docker image) to get this.

**A neural TTS engine now recovers if its helper process stops.** In the app
and on the server, if the audio.cpp helper behind those four engines crashed or
was killed, every later request failed until a restart. It is now noticed on
the next request, restarted, and the log records how it ended and the last
thing it printed.
