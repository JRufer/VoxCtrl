**Fixed: server text-to-speech stopped working seconds after the server
started.** With Pocket-TTS, Kitten TTS 2, Breeze-TTS-2 or VoxCPM2 as the
server's engine, speech requests failed with "Connection refused" to a
`127.0.0.1` address. The engine's helper process was being shut down a few
seconds after it started. The server now keeps it running for as long as the
server does. Only `voxctrl-server` changed: rebuild the server (or its Docker
image); clients do not need updating for this fix.
