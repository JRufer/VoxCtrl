**New: AI processing through a VoxCtrl server.**

The AI-processing step (a hotkey sending what you dictated to a language model
to be rewritten) can now go through your VoxCtrl server instead of each
computer connecting to the model's service itself.

- **On the server:** point it at any OpenAI-compatible service with
  `VOXCTRL_SERVER_LLM=true`, `VOXCTRL_SERVER_LLM_ENDPOINT` and
  `VOXCTRL_SERVER_LLM_MODEL` (or `[llm]` in `server.toml`). The service's
  address and API key stay on the server.
- **In the app:** turn on **Use the VoxCtrl server** under **Settings → OpenAI
  API**, or **Use the server for AI processing** under **Settings → Engine**.
  **Check the server** shows the model it answers with.
- Your prompts and per-hotkey settings are unchanged; the model is the
  server's. With encryption on, the text is encrypted on the way.
- If the request can't be answered, the text is typed as you dictated it.

Off by default at both ends. Needs the server and the app on 0.9.16. See
[AI processing through the server](https://github.com/JRufer/VoxCtrl/blob/master/docs/server.md#ai-processing-through-the-server).
