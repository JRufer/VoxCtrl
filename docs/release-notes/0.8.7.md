**Fixed: a black rectangle on screen at all times on desktops without
compositing** ([#181](https://github.com/JRufer/VoxCtrl/issues/181)). The
overlay window stays on screen while idle and relies on being transparent to
stay invisible. Transparency needs the desktop's compositor, so with
compositing turned off (for example Xfce with *Enable display compositing*
unchecked) the idle overlay showed as a solid black box from startup, even with
the overlay turned off in Settings.

VoxCtrl now checks whether the desktop composites windows. If it doesn't, the
overlay is shown only while it has something to display, and hidden again as
soon as it's done. You may see a brief dark frame as it appears, since without
a compositor nothing can be see-through. Turning compositing on or off while
VoxCtrl is running is picked up straight away. Desktops with a compositor
(KDE, GNOME, Hyprland, and Xfce with compositing on) behave exactly as before.
