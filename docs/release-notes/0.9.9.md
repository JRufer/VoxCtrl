**Clearer error when a neural TTS engine stops mid-request.** When the helper
process behind Pocket-TTS, Kitten TTS 2, Breeze-TTS-2 or VoxCPM2 died while
speaking, the error was a bare "connection closed before message completed".
It now says that the engine stopped, how it ended, and the last thing it
printed (for example running out of memory, or a graphics driver failure), in
the app's error message and in the server's log. This does not fix such a
crash; it shows the reason for it.
