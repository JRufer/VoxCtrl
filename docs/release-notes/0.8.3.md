**New: Phonon-2, a more accurate English speech engine for the Parakeet
backend.**

In Settings → Engine, with Parakeet selected, you can now pick **Phonon-2
(English only, ~735 MB)**. It is Fermion Research's retrain of Parakeet TDT
0.6B v3 with roughly 2-bit encoder weights, and it averages 5.2% word error
on the Open ASR Leaderboard's English sets — ahead of the Redux variant
(5.7%) and close to the full-size Parakeet v3 (5.0%). Because it only
transcribes English, the Language field is hidden for it. Fermion ships the
model in a format only its own runtime reads, so VoxCtrl downloads the
community ONNX conversion
[`tiyuvta/Phonon-2-ONNX`](https://huggingface.co/tiyuvta/Phonon-2-ONNX). It
uses about 1.1 GB of RAM once loaded. Phonon-2 is credited in About
(CC-BY-4.0).

**Improved: long recordings with any Parakeet model.** Audio longer than 35
seconds is now split into 25–35 second pieces, each cut at the quietest
moment in that range so the cut lands in a pause between words, and the
transcripts are joined. This keeps memory use flat on long dictations; the
speech engine's memory cost otherwise grows with the square of the recording
length.

**Improved: model downloads.** Model files are now written to disk as they
arrive instead of being held in memory first, and a download that ends short
is discarded instead of being kept as if it had finished.

### Notes

Phonon-2 is a third-party conversion, not Fermion's own release. Switching
models downloads the new files; your existing Parakeet models are untouched.
