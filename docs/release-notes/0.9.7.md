**Fixed: VoxCtrl would not start on Windows.** The Windows installer left out
three libraries the app needs for GPU acceleration, so on a PC that had never
built VoxCtrl from source it failed at launch with a "webgpu_dawn.dll was not
found" error. The installer now includes them, and Moonshine and Parakeet can
use the GPU as intended. If you installed an earlier release on Windows,
download this installer and run it over the top. Thanks to
[@chezhenkie](https://github.com/chezhenkie) for finding and fixing this.

**Added: credits and licences for the GPU libraries.** Settings → About now
credits Dawn and the DirectX Shader Compiler, and the Windows installer puts
their licence texts in a `licenses` folder next to the app.
