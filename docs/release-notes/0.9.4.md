**New: dictation cleanup can run on the server.** A VoxCtrl server can now run
S1-mini dictation cleanup for its clients, so a client that already sends its
transcription to the server loads no language model of its own.

- **On the server:** set `VOXCTRL_SERVER_CLEANUP=true` (Docker) or
  `[cleanup] enabled = true` in `server.toml`, and restart. It downloads the
  S1-mini model (about 470 MB) and keeps it loaded. A Docker image has to be
  rebuilt for this release; it now includes the cleanup helper.
- **On each client:** tick **Settings → Engine → Remote Speech Engine Settings
  → Run dictation cleanup on the server**. The line under it says whether the
  server offers cleanup and what to change if it does not.

Whether a dictation is cleaned, the cleanup style and the per-app styles are
still set on the client and sent with each request, so several clients can
share one server with different settings.

If the server can't clean a dictation, because it is unreachable, has cleanup
turned off or takes too long, the text is typed as it was said. The client does
not fall back to cleaning it locally.

With the option on, **Clean up models** treats a local copy of S1-mini as no
longer in use and offers to remove it.

Cleanup is off by default at both ends, so nothing changes until you turn it
on. The full guide is in `docs/server.md` under "Dictation cleanup on the
server".
