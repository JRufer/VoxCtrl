**Faster from releasing the key to the text appearing.** Several waits that
sat between letting go of the dictation key and the paste are gone:

- **Live text stops when you let go.** If a live-text pass was still running
  when you released the key, the final transcription used to wait for it to
  finish. Releasing now stops it, so the final transcription starts at once.
  The overlay keeps showing what it had until the final text replaces it, as
  before.
- **Quicker clipboard backup on Wayland.** Before pasting, VoxCtrl saves
  everything on your clipboard so it can put it back afterwards. It used to
  read each format one after another; it now reads them all at once, and at
  the same time as it works out which paste shortcut the window needs.
- **No wasted attempt on KDE and GNOME.** VoxCtrl no longer tries `wtype` to
  send the paste shortcut there, since it can't work on those desktops.
- **The cleanup model loads while you speak.** When S1-mini cleanup is on, the
  model now starts loading as soon as you press the key, instead of after you
  release it, so the first dictation after starting VoxCtrl doesn't wait for
  it.

**See where the time goes.** Each dictation now logs how long it took after
you released the key: when the transcript was ready, how long transcription
and cleanup took, and when the text was delivered. Only timings are logged,
never what you said. See [Pasting](../paste.md#troubleshooting) for what each
line means.

**Fixed: Linux builds.** A change in the AppImage packaging tool, made after
0.8.5, stopped the Linux AppImages from building. They build again.
