**New: Kitten TTS 2 voice engine.** Pick **Kitten TTS 2** in Settings → Text to
Speech, or in the setup wizard. It is a 1.7B-parameter model by KittenML with
built-in voices: 38 English ones, plus voices for Arabic, Chinese, French,
German, Hindi, Italian, Portuguese, Russian and Spanish. To speak one of those
languages, choose its voice and write the text in that language. It can also
clone a voice from a 1–30 second clip in your voice folder, as long as a `.txt`
file next to the clip holds exactly what is said in it. A **Delivery** setting
switches between steady and more expressive speech, and text can start with an
emotion tag such as `[excited]` or include `<sigh>` or `<laugh>`. Numbers,
prices, percentages and times are spelled out before they are spoken. The model
is a 3.3 GB download and needs several GB of memory. Its GPU option is
experimental: the model's runtime has been tested on CPU and NVIDIA CUDA, and
VoxCtrl uses its Vulkan build.

**Updated: the audio.cpp runtime moves to v0.9.4.** Pocket-TTS, Breeze-TTS-2,
VoxCPM2 and Kitten TTS 2 all run on it. If you already have an older runtime,
it is updated the next time you download any of those models; until then your
current engine keeps working as before.

**Fixed: large voice-model downloads could fail.** Model files were held
entirely in memory while downloading and had five minutes to finish, so a
multi-gigabyte model such as Breeze-TTS-2 failed on slower connections. They now
stream to disk with no overall time limit, and a download that stops partway is
never mistaken for a finished model. Each model is also stored once instead of
being kept in a download cache as well, which frees the space of a second copy
for models downloaded from now on.

**Fixed: Breeze-TTS-2's voice description was never sent.** For configs still
using Voice Design, the prompt was sent in a field audio.cpp does not read. It
is now sent where audio.cpp expects it. Voice Cloning, the mode Settings offers,
is unaffected.
