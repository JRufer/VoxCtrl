**New: clean up models you no longer use.** Settings → Engine → Downloaded
Models has a **Clean up models…** button that lists every speech, cleanup and
voice model you have downloaded, with its size, and removes the ones you
confirm. It is meant for anyone who ran everything on their own computer and
has since moved transcription to a server, where gigabytes of local models are
left behind, but it works with a local engine too.

- Anything in use is kept and shown with the reason: the selected speech
  engine's model, the fallback engine's model, S1-mini while dictation cleanup
  is on for anything, and the selected voice while text-to-speech is on.
- With a remote speech engine, the dialog asks you to pick the fallback engine
  first and saves the answer. That engine's model is the one kept; with no
  fallback, no speech model is kept and the dialog warns that dictation will
  fail while the server is unreachable.
- Custom voices are never removed. Neither are the Piper and audio.cpp
  programs, or files in a model folder of your own that VoxCtrl did not
  download.

A removed model can be downloaded again by selecting it in Settings.
