**New: the AppImage is also the server.**

```bash
./VoxCtrl-linux-x86_64-vulkan.AppImage --server
```

runs the VoxCtrl server from the same file you already downloaded, with no
window, tray icon or microphone. Nothing to build and no Docker needed: start
it on your desktop, paste the pairing code it prints into the app on your
laptop, and the laptop dictates through the desktop.

- Everything after `--server` is a server option: `--server --pairing-code`,
  `--server --print-config`, `--server --help`.
- It uses the app's model folder, so models the app already downloaded are not
  downloaded again, and the GPU build gives the server the same acceleration.
- The `.deb` works the same way: `voxctrl --server`.
- The server guide shows how to start it automatically with a systemd user
  service.

It needs a machine with desktop libraries installed (any desktop Linux; it runs
over SSH with nobody logged in). For a minimal headless server, keep using
Docker or the system service. See
[Run it from the VoxCtrl AppImage](https://github.com/JRufer/VoxCtrl/blob/master/docs/server.md#run-it-from-the-voxctrl-appimage).
