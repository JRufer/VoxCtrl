**New: VoxCtrl on the AUR.** On Arch, Manjaro, EndeavourOS, CachyOS and other
Arch-based systems, install with `paru -S voxctrl-bin` (or `yay -S voxctrl-bin`)
and update with the rest of the system. `voxctrl-bin` repackages this release's
WebGPU build, so Moonshine and Parakeet can use the GPU as well as whisper.cpp.
`voxctrl` builds the same release from source, and `voxctrl-git` builds the
latest development version. All three bring `wtype` with them, so dictation
types into other windows on Wayland straight away; on X11, add `xdotool`. See
[Installation](https://github.com/JRufer/VoxCtrl/blob/master/docs/installation.md#arch-linux-aur).

**Changed: an install your package manager owns now behaves like one.**

- When the package ships its own launcher (the AUR packages do), VoxCtrl no
  longer writes a second one into `~/.local/share/applications` on every start.
  A launcher an earlier launch or a deleted AppImage left there is removed, so
  the menu shows one VoxCtrl and nothing is left behind after uninstalling. A
  launcher for an AppImage you still keep is left alone.
- The setup window no longer offers to run `pacman -S` or `apt-get install`
  with administrator rights on a packaged install. If the typing helper is
  missing, it shows the one command that adds it.
- Bug reports say `package (pacman)` or `package (dpkg)` instead of a bare
  `installed`, which tells us which packaging a problem came from.

**Changed: the `.deb` installs Dawn privately.** The WebGPU `.deb` now puts
`libwebgpu_dawn.so` in `/usr/lib/voxctrl/` instead of `/usr/lib/`, so it can't
collide with another package's copy. Nothing to do: upgrading moves it.

**New: `SHA256SUMS`.** Every release now lists the checksum of each download.
Check one with `sha256sum -c --ignore-missing SHA256SUMS`.
