**Fixed: the Linux WebGPU AppImage crashed at launch on CPUs without
AVX-512.**

0.8.0 and 0.8.1 were built on a GitHub runner whose CPU supports AVX-512, and
the speech engine (whisper.cpp) was compiled for exactly that CPU — so on
anything older it died with an "illegal instruction" the moment the first
transcription thread started. That includes AMD Ryzen 5000 and earlier and
most Intel desktop chips. Because GitHub's runners are a mix of CPUs, it only
broke on some builds, which is why earlier releases happened to work.

whisper.cpp is now built for a fixed baseline — AVX2, FMA and F16C, which
every x86-64 CPU from 2013 (Intel Haswell) and 2017 (AMD Zen) onward has — and
never for the build machine's own CPU. The other speech engines and the
S1-mini helper were not affected.

0.8.1's separate fix (a bundled `libsharpyuv` shadowing the system's) is
included. If 0.8.0 or 0.8.1 crashed on launch for you, download the
`-linux-x86_64-vulkan-webgpu.AppImage` from this release.

### Notes

A CPU without AVX2 (Intel before Haswell, AMD before Zen) is no longer
supported by the Linux builds.
