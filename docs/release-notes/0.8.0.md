**GPU acceleration for every engine, with one switch to control it.**

Moonshine and Parakeet can now run on your GPU, not just Whisper.cpp, and
every engine is turned on or off the same way: a **GPU acceleration**
checkbox in **Settings → Engine** (Whisper.cpp, Moonshine, Parakeet),
**Settings → Features** (S1-mini) and **Settings → Text to Speech**. The
Whisper.cpp *Device* dropdown is gone; the checkbox replaces it, and existing
settings carry over.

A chip beside each engine's name now says which device it is using — for
example `✔ Ready (Vulkan (AMD/Intel/NVIDIA))` or `✔ Ready (CPU)` — so it is
always clear when the GPU is in play. S1-mini's chip follows its own
checkbox, too.

**WebGPU for Moonshine and Parakeet.** ONNX Runtime has no Vulkan backend, so
these two engines use its WebGPU provider instead (Direct3D 12 on Windows,
Vulkan underneath on Linux). The Windows installer now includes it for both
engines. On Linux it ships as a second download,
`-linux-x86_64-vulkan-webgpu.AppImage`, because the GPU library it bundles
needs glibc 2.38 or newer and would not start on Ubuntu 22.04 or Debian 12 —
those keep using the plain Vulkan AppImage, and the updater never moves an
install onto a build it cannot run.

**Parakeet starts on the CPU, on purpose.** Its INT8 models do most of their
work on the CPU even with the GPU provider registered. Measured on an RTX 4090,
the standard model was about four times slower on WebGPU, and Redux only
marginally faster. Turn **GPU acceleration** on in **Settings → Engine** if
your hardware behaves differently.

**S1-mini** can be switched between the GPU and the CPU without restarting;
the change applies to the next cleanup.

### Notes

Each engine reloads its model when you change its checkbox. The setting is
stored as `engine.moonshine.device`, `engine.parakeet.device` and
`engine.s1_mini.gpu`.
