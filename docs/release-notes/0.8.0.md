**GPU acceleration for every engine, with one switch to control it.**

Moonshine and Parakeet can now run on your GPU, not just Whisper.cpp, and
every engine is turned on or off the same way: a **GPU acceleration**
checkbox in **Settings → Engine** (Whisper.cpp, Moonshine, Parakeet),
**Settings → Features** (S1-mini) and **Settings → Text to Speech**. The
Whisper.cpp *Device* dropdown is gone; the checkbox replaces it, and existing
settings carry over.

A chip beside each engine's name now says which device it is using — for
example `✔ Ready (Vulkan (AMD/Intel/NVIDIA))` or `✔ Ready (CPU)` — so it is
always clear when the GPU is in play. S1-mini's chip follows its own
checkbox, too.

**WebGPU for Moonshine and Parakeet.** ONNX Runtime has no Vulkan backend, so
these two engines use its WebGPU provider instead (Direct3D 12 on Windows,
Vulkan underneath on Linux). The Windows installer now includes it for both
engines. On Linux it ships as a second download,
`-linux-x86_64-vulkan-webgpu.AppImage`, because the GPU library it bundles
needs glibc 2.38 or newer and would not start on Ubuntu 22.04 or Debian 12 —
those keep using the plain Vulkan AppImage, and the updater never moves an
install onto a build it cannot run.

**Moonshine and Parakeet start on the CPU, on purpose.** Both run part of
their work on the CPU even with the GPU provider registered, and pass data
back and forth on every decoding step. Measured on an RTX 4090, Moonshine and
Parakeet were 5–7× slower on WebGPU (S1-mini and Whisper.cpp were the ones
that gained). Turn **GPU acceleration** on in **Settings → Engine** if your
hardware behaves differently.

**New: Speed test.** Whether the GPU helps depends on your machine, so
**Settings → Engine → Speed test** measures it: it times each downloaded
engine on the CPU and on the GPU with a short speech clip, shows the results
and recommends the faster device for each, with one button to apply them. It
shows how long it expects to take (usually under a minute), a progress bar
with the time left, and can be cancelled.

**S1-mini** can be switched between the GPU and the CPU without restarting;
the change applies to the next cleanup.

**Fixed: S1-mini never actually ran on the GPU in packaged builds.** The
build step that stages the helper process rebuilt it without Vulkan and
bundled that CPU-only copy over the Vulkan one, while Settings said Vulkan.
Packaged builds now ship the Vulkan helper (cleanups measured ~60 ms instead
of ~300–450 ms on an RTX 4090), and Settings asks the helper which backend it
really has instead of assuming — so it says CPU when that is the truth. The
first cleanup after loading the model on the GPU is slower while the GPU
compiles its shaders.

### Notes

Each engine reloads its model when you change its checkbox. The setting is
stored as `engine.moonshine.device`, `engine.parakeet.device` and
`engine.s1_mini.gpu`.
