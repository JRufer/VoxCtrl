**New: the built-in overlays show when the speech server is offline.** While a
remote speech engine is selected and its server can't be reached, every
built-in overlay style now carries a small OFFLINE mark in its own status line,
in the same amber as the tray icon's badge — a second stamp beside REC on the
Voice Card, `[offline]` in the Terminal's title bar, a lamp beside the
Vinyl meter's, and so on. It tells you, where you are already looking, that
this dictation is running on the fallback engine or is about to fail. With a
local engine or a reachable server nothing is drawn and each style looks
exactly as it did.
