**New: live text with a remote speech engine.** Overlays now show words as you
speak when transcription runs on a server, as they do with a local engine.
While you talk, the app sends the server short clips of what you have said so
far; the dictation itself is still sent separately, so a slow live update never
costs you the transcript. Early command detection works over a server too. This
applies to any OpenAI-compatible server, not only `voxctrl-server`, and the
server needs no update. A busy or slow server will see several small requests a
second per person speaking; turn off **Show live transcript in overlay** to
stop them.

**New: overlays drop their text area when live text can't be produced.** If the
server is lost, live text carries on with the fallback engine when that is fast
enough. Otherwise each overlay goes back to its layout without the text area,
rather than showing one nothing will fill, and gets it back when the server
returns.

**New: overlays can show the offline state.** Custom overlays get one more live
value, `--voxctrl-offline`, which is `1` while a remote speech server is
selected and cannot be reached.

**New: the built-in overlays show when the speech server is offline.** While a
remote speech engine is selected and its server can't be reached, every
built-in overlay style now carries a small OFFLINE mark in its own status line,
in the same amber as the tray icon's badge — a second stamp beside REC on the
Voice Card, `[offline]` in the Terminal's title bar, a lamp beside the
Vinyl meter's, and so on. It tells you, where you are already looking, that
this dictation is running on the fallback engine or is about to fail. With a
local engine or a reachable server nothing is drawn and each style looks
exactly as it did.

**Fixed: per-app cleanup styles were ignored with a remote speech engine.** A
remote transcript did not carry the id of its recording, so the app it was
dictated into could not be matched to it and the default style was always used.

**If you updated to 0.9.0 early, this release also brings you** the fallback
engine for when the server can't be reached, the offline indicator in the tray,
and the fix for hotkeys staying switched off after the setup wizard. They were
added to 0.9.0 after it was first published, without a new version number, so
an app that had already updated never saw them. They are described in the
0.9.0 notes.

**There is no 0.9.1.** It was superseded by this release before it was published;
everything it would have contained is listed above.
